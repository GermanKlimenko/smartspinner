# Умный спиннер для трейдера

Инженерный проект карманного POV-дисплея: трёхлучевой спиннер диаметром 100 мм с 45 верхними и 36 торцевыми RGB-пикселями, BLE на nRF52 и синхронизацией по датчику Холла.

## Сайт проекта

Сайт содержит описание концепции, электроники, механики, планы производства, чертежи и прямые ссылки на все файлы v0.2.

После включения GitHub Pages он будет доступен по адресу:

**https://germanklimenko.github.io/smartspinner/**

## Текущий статус

Механическая модель v0.2, STL/STEP, контуры PCB, макеты KiCad и размерные чертежи готовы. Электроника пока является макетом размещения; перед производством необходимо закончить электрическую схему, трассировку, расчёт питания и подготовить Gerber/BOM/CPL.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

Полный архив проекта находится в `public/project-files/Ticker_Spinner_v0_2_package.zip`.
