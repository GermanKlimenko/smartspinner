# Умный спиннер для трейдера

Инженерный проект карманного POV-дисплея: четырёхлучевой спиннер диаметром 100 мм с 80 верхними и 48 торцевыми RGB-пикселями, BLE на nRF52 и синхронизацией по Hall + IMU.

## Сайт проекта

Сайт содержит описание концепции, электроники, механики, планы производства, чертежи и прямые ссылки на все файлы v0.3.

После включения GitHub Pages он будет доступен по адресу:

**https://germanklimenko.github.io/smartspinner/**

## Текущий статус

Механическая модель v0.3, STL/STEP, контуры PCB, пятилистовой размерный чертёж и партнёрские визуализации готовы. Электроника пока является компоновочным макетом; перед производством необходимо закончить электрическую схему, трассировку, расчёт питания и подготовить Gerber/BOM/CPL.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

Полный архив проекта находится в `public/project-files/ticker_spinner_v0_3_complete_package.zip`.
