# Умный спиннер для трейдера

Инженерный проект карманного POV-дисплея: четырёхлучевой спиннер диаметром 100 мм с 80 верхними и 48 торцевыми RGB-пикселями, BLE на nRF52 и синхронизацией по Hall + IMU.

## Сайт проекта

Сайт содержит описание концепции, электроники, механики, планы производства, чертежи и прямые ссылки на механику v0.3, принципиальную схему v0.5 и PCB-пакет v0.4.

После включения GitHub Pages он будет доступен по адресу:

**https://germanklimenko.github.io/smartspinner/**

## Текущий статус

Механическая модель v0.3, STL/STEP, контуры PCB, пятилистовой размерный чертёж и партнёрские визуализации готовы. Для электроники добавлена редактируемая принципиальная схема KiCad v0.5, PDF, GPIO pin-map и ERC-отчёт; пакет v0.4 содержит существующие KiCad-платы, обзорные Gerber и drill, BOM, CPL, расчёт питания и план первого запуска.

Электроника имеет статус **engineering review package**, а не «готово в производство». Схема v0.5 исправляет недоработку прежнего пакета: PDF v0.4 был архитектурным описанием, а не принципиальной схемой. Повторяющиеся LED-цепи в v0.5 пока представлены эквивалентными блоками; перед заказом нужно развернуть и аннотировать все 128 LED, синхронизировать схему с PCB, сверить точные MPN/footprints, закрыть ERC/DRC и пройти DFM.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

Полный архив проекта находится в `public/project-files/ticker_spinner_v0_3_complete_package.zip`.

Новый пакет для подрядчика находится в `public/project-files/SmartSpinner_v0_5_RFQ_Send_Package.zip`, а отдельная схема — в `public/project-files/SmartSpinner_v0_5_schematic_review.zip`.
