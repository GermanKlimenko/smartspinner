# Умный спиннер для трейдера

Инженерный проект карманного POV-дисплея: четырёхлучевой спиннер диаметром 100 мм с 80 верхними и 48 торцевыми RGB-пикселями, BLE на nRF52 и синхронизацией по Hall + IMU.

## Сайт проекта

Сайт содержит описание концепции, электроники, механики, планы производства, чертежи и прямые ссылки на механику v0.3 и электро-пакет v0.4.

После включения GitHub Pages он будет доступен по адресу:

**https://germanklimenko.github.io/smartspinner/**

## Текущий статус

Механическая модель v0.3, STL/STEP, контуры PCB, пятилистовой размерный чертёж и партнёрские визуализации готовы. Для электроники v0.4 сформированы KiCad-платы, обзорные Gerber и drill, BOM, CPL, электрическая спецификация PDF, расчёт питания и план первого запуска.

Электроника v0.4 имеет статус **engineering package for quotation/layout completion**, а не «готово в производство»: LED-цепи разведены, но в приложенных DRC-отчётах остаются незакрытые центральные и интерфейсные соединения. Перед заказом нужно закрыть DRC до нуля, сверить land patterns, завершить пассивную обвязку питания и пройти DFM.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

Полный архив проекта находится в `public/project-files/ticker_spinner_v0_3_complete_package.zip`.

Электро-пакет находится в `public/project-files/SmartSpinner_v0_4_electronics_ERC.zip`.
