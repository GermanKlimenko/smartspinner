## Текущий этап: неподвижный стенд B0.1

Документация для опытной ручной сборки подготовлена. **На железе не проверено.**
Цель конечного устройства: четыре луча, Ø100 мм, по 20 верхних и 12 торцевых RGB. Это целевые параметры, не характеристики испытанного образца.

## Старые версии сняты

**STOP FABRICATION. Прежние электрические файлы v0.4/v0.5 нельзя использовать для изготовления и подключения аккумулятора.**

Удалены из текущего каталога устаревшие версии v0.1/v0.2, электрические пакеты v0.4/v0.5 и прежние материалы с завышенной оценкой готовности. Они восстановимы из истории Git. Аудит относится к историческому коммиту [1635129](https://github.com/GermanKlimenko/smartspinner/tree/1635129707aff4e6b09a5e4b1feb32eedf14c7ca), поэтому его пути и контрольные суммы описывают именно тот снимок.

Сохранена параметрическая геометрия v0.3 как основа для переработки, а не согласованная с электроникой сборка. Визуализации — концептуальные рендеры, не фотографии работающего прототипа.

## Следующие шаги

1. Купить компоненты по списку B0.1 и собрать неподвижный стенд.
2. Проверить адресацию, токи, отключение, нагрев и оптические импульсы; заполнить протокол.
3. По результатам разработать новую компактную схему и PCB, согласовать с корпусом.
4. После ERC/DRC, DFM и проверки питания подготовить заказ 10 PCBA.

## Локальный запуск сайта

Node.js >= 22.13, pnpm. Команды: `pnpm install --frozen-lockfile`, `pnpm dev`, `pnpm build`.
Публикация — GitHub Pages через workflow в `.github/workflows/pages.yml`.
