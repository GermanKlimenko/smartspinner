# SmartSpinner B0.1 - настольный стенд

Это сокращённая копия для сайта. Полные исходники и прошивка: https://github.com/GermanKlimenko/smartspinner/tree/main/bench/v0.1 . Полный ZIP: ../SmartSpinner_B01_DIY_Package.zip . PDF в этой папке: SmartSpinner_B01_Bench.pdf.

Дата: 29.09.2026. Статус: **документация для опытной ручной сборки; на железе не проверено**.

Это отдельная ветвь исследований, а не новая производственная версия спиннера. Старые v0.3-v0.5 не используются как проверенные схемы. Ничего из этого комплекта нельзя закреплять на работающем голографическом вентиляторе.

Начать с `manual.md` или `output/pdf/SmartSpinner_B01_Bench.pdf`. Полная таблица проводов: `wiring.html`; машиночитаемые соединения: `wiring.json`. Схема питания и управления: `schematic.svg`. Детальный список покупок: `shopping.md` и разделы 2-3 инструкции. Прошивка: `firmware/spinner_bench/`.

## Результат этапа

Один неподвижный эквивалент луча: 20 верхних + 12 торцевых RGB, 6 драйверов SM16306SJ, около 5 мА на цветовой канал. Все 32 LED лежат на столе. Arduino UNO R3 - временный генератор тестовых сигналов, не замена nRF52 в конечном устройстве. Выводные LED диаметром 5 мм выбраны ради удобства пайки, а не для установки в корпус Ø100 мм.

Проверяем адресацию 96 каналов, ток, отключение, обмен и оптические импульсы. Не проверяем читаемость POV, ресурс аккумулятора, BLE, балансировку, Hall-синхронизацию, четыре луча одновременно и безопасность вращения. Для них нужны следующие прототипы.

## Сборка программной части

Arduino IDE: установить Arduino AVR Boards 1.8.8, выбрать **Arduino Uno**, открыть `.ino`, загрузить только при отключённом LED-питании и S1=OFF. Монитор порта: 115200, окончание строки Newline. **Uno R4, Nano ESP32 и UNO R3 3.3V не подходят под эту прошивку**.

CLI из каталога этого пакета:

```sh
arduino-cli compile --fqbn arduino:avr:uno --output-dir build/uno firmware/spinner_bench
c++ -std=c++11 -Wall -Wextra -Werror tests/test_core.cpp -o /tmp/spinner_bench_test
/tmp/spinner_bench_test
python3 tools/verify_wiring.py
```

`build/verification.txt` фиксирует выполненные программные проверки, не физические испытания. `test_record.md` заполняется после сборки; сейчас все измерения **НЕ ПРОВЕДЕНЫ**.

## Как воспроизвести документы

Python 3 с reportlab, pypdf: `python3 tools/build_docs.py`. Генератор создаёт PDF, SVG, HTML и JSON; не изменяет старый проект. `manual.md` - редактируемый русский оригинал. Официальные datasheet не перепакованы в архив: ссылки даны в инструкции. Сверять ориентацию корпусов с ними обязательно.

## Что не заказывать сейчас

Не покупать аккумуляторы, зарядные платы, мотор, корпус, готовые производственные платы спиннера и 128 миниатюрных RGB. Не заказывать Gerber из старого проекта. Для стенда заказ PCB не нужен: макетные платы и переходники. Если нет точного SM16306SJ или совместимого QSOP24-переходника, остановить закупку этих позиций, прислать карточку аналога для проверки; не подменять автоматически.
