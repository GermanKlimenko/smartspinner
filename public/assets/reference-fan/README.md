# Реальные фотографии LED-вентилятора

Снимки предоставлены владельцем проекта Германом, 29.09.2026; опубликованы с его разрешения. Это купленный POV-вентилятор, а не изготовленный SmartSpinner.

- [LED с миллиметровой линейкой](led-ruler.jpg)
- [Обратная сторона: маркировка SM16306SJ](driver-sm16306sj.jpg)
- [Крупный план LED-линейки](led-closeup.jpg)

Точный артикул и корпус светодиода по фото не установлен. Показатели продавца не считаются измеренными характеристиками. Эти фото помогают выбирать эксперимент, но не доказывают работоспособность нашей схемы.

При подготовке нормализирована ориентация и удалены EXIF/GPS-метаданные. Содержимое устройства не ретушировалось. Оригиналы остались у владельца. Купленный вентилятор не предназначен для крепления самодельного стенда на вращающиеся лопасти.
